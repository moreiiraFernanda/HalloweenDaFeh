# HalloweenDaFeh
O COVEN MEDIEVAL — versão 2

Esta versão não contém hospedagem. A estrutura foi refeita para:
- festa privada/lista de presença;
- data 07/11/2026, 19h–00h;
- Residencial Soft São Luís, 155 — Salão 2;
- comida inclusa no ingresso;
- bebidas por conta dos convidados;
- coquetel de boas-vindas;
- dress code temático;
- confirmação até 10/10/2026;
- contador regressivo;
- botão pronto para o Google Forms.

Publicação:
1. Crie um repositório público no GitHub.
2. Envie index.html, style.css e script.js.
3. Settings > Pages > Deploy from branch > main.
4. Use o endereço gerado pelo GitHub para criar o QR Code.

Google Forms:
No script.js, substitua const RSVP_URL = ""; pelo link do formulário.
